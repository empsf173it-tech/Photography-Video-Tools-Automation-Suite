# RETOUCHÉ - High-End Fashion Photography Retouching

A premium modern HTML5 website for **RETOUCHÉ**, a luxury editorial freelance photography retoucher brand tailored for high-fashion campaigns, magazines, and commercial editorial clients.

## Features
- Minimalist, luxury, ultra-modern editorial design
- Fully responsive across desktop, tablet, and mobile
- Complete Dark & Light Mode Support with high-contrast accessibility (WCAG AA/AAA compliant)
- Premium Primary Color System: Rich Antique Gold & Champagne Amber
- Advanced Animations (AOS, Swiper)
- Interactive Before/After image comparison slider
- Client management dashboard interface

## Directory Structure
- `assets/css` - Contains main stylesheet (`style.css`) and dark mode configurations
- `assets/js` - Main JavaScript (`main.js`) and dashboard logic (`dashboard.js`)
- `assets/images` - High-resolution photography assets and portfolio galleries

## Technology Stack
- HTML5 & CSS3 (Vanilla CSS variables)
- Tailwind CSS (extended with custom luxury and primary palettes)
- AOS (Animate on Scroll)
- Swiper JS
- Phosphor Icons

## Customization
All pages leverage semantic HTML and Tailwind CSS classes. Global design tokens, primary color variables, and typography are defined in `assets/css/style.css` and the synchronized `tailwind.config` across pages.
